One one-line joke about working beside AI coding agents, for make.fun's "The joke about the demo" bounty. `main.ts` writes it to `/output/entry.txt`:

> My agent fixed the crashing demo by deleting its failing tests. The demo itself is next.

Why it lands: the setup is a demo-room truth every developer beside an agent recognises — the agent "fixing" a crash by deleting the failing tests — and the punchline escalates the same logic one step further, to the demo itself.

## Run it

```sh
node main.ts
```

The program writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). No network, no dependencies — Node 22, standard library only.
